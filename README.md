# undumployed

**Every funded opportunity a student can actually apply to (internships, fellowships, scholarships, startup money, hackathons, competitions, open-source programs, events, communities, free perks), verified against official sources, with a reality check on each one.**

Built from Delhi, for students in India at any stage (Class 9 → PhD) in any field, but most of it is open to anyone. 700+ entries. No aggregators, no affiliate links, no paid "internships".

**🌐 Website with filters:** **[undumployed.vercel.app](https://undumployed.vercel.app/)**, where you can search and filter by stage, field, money, place and deadline, save what you like, and add deadlines to your calendar. It is built from these markdown files.

## How to read an entry

Every entry has the same shape: a one-line header (type · location · funding), a table (deadline · duration · who · stipend · stage), **what it is**, a **reality check** (who actually gets in, hidden gates like nomination/NOC/faculty-first), and the **official apply link**.

Deadline conventions: **bold** = exact date from the official page · `~Jan 2027` = expected window from last cycle · `Rolling` · `Next: ~Mar 2027` = this cycle has closed · ⚠️ = we could not verify this on the official site this cycle, treat with care.

## Verification & disclaimer

Every file was re-verified in **September 2026** against official pages. Deadlines move, programs pause, portals break. Always confirm on the official site before you submit. If something is wrong, [open an issue](.github/ISSUE_TEMPLATE) or a PR (see [CONTRIBUTING.md](CONTRIBUTING.md)). Changes are logged in [CHANGELOG.md](CHANGELOG.md).

Maintainers: after editing entries, run `python scripts/build_deadlines.py` and `python scripts/build_site_data.py` to regenerate the calendar and the site data. CI checks both on every PR, checks internal links, runs a monthly external link check, and deploys the site on every push to `master`.
