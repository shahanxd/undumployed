## Visa Quick Reference — Indian Passport

| Destination | Visa | Ease |
|-------------|------|------|
| **USA** | B1/B2 (interview required) | ⚠️ Hard — long wait times. Apply 4–6 months early. |
| **UK** | Standard Visitor Visa | Moderate |
| **EU / Schengen** | Schengen Visa | Moderate |
| **Japan** | Tourist visa via VFS | Moderate |
| **Taiwan** | Conditional — visa-free if holding valid US/UK/Schengen/Japan visa | Easy if qualified |
| **UAE (Dubai)** | Conditional — visa-on-arrival with valid US/UK/EU; otherwise e-Visa | Easy–Moderate |
| **Singapore** | Apply via VFS | Moderate |
| **Turkey** | e-Visa (online, usually instant) | Very Easy |
| **Australia** | Visitor visa subclass 600 | Moderate |
| **South Korea** | Tourist visa via VFS | Moderate |
| **Canada** | Visitor visa | ⚠️ Hard |

> **Pro tip:** A US B1/B2 visa unlocks conditional visa-free access to Taiwan and visa-on-arrival in UAE — making subsequent trips much easier.
