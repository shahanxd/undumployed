# Contributing

Thank you for helping make this better. Every verified addition or correction helps someone not miss a deadline.

---

## What we're looking for

- **New opportunities** — programs not currently listed
- **Deadline corrections** — programs that have updated their dates
- **Dead links** — apply URLs that no longer work
- **Reality checks** — if your application experience contradicts what's written, flag it
- **New events** — conferences, festivals, expos worth knowing about

---

## What we don't want

- Affiliate links or referral links of any kind
- Programs you haven't verified on the official website
- "Apply here" links that redirect to a third-party aggregator instead of the official source
- Vague entries without a deadline, stipend info, or apply link

---

## Entry format

Every entry must follow this format:

```markdown
### [Program Name](official-apply-url)
> **Type:** [Research Internship / Fellowship / Scholarship / Startup / Hackathon / Event / Insider]
> **Location:** [City, Country] | **Funded:** [✅ Full / ✅ Stipend / ✅ Paid / ❌ Unpaid / ❌ Free]

| Field | Details |
|-------|---------|
| Deadline | [Date or "Rolling" or "Annual — watch [site]"] |
| Duration | [X weeks / X months] |
| Who | [Clear eligibility — year, field, nationality, any hard gates] |
| Stipend | [Amount and currency, or "Fully funded (flights + housing + stipend)"] |

**What it is:** One paragraph. What you actually do, what you get, why it matters.

**Reality check:** Who realistically gets in. What the actual competition looks like. What trips people up.

**Prep steps:**
1. First concrete step
2. Second concrete step

**Apply:** [official-apply-url](url)
```

**The reality check is mandatory.** It's what makes this repo useful vs a list of links.

---

## How to submit

1. Fork this repository
2. Add or edit the relevant file
3. Open a pull request with:
   - A short title: e.g., "Add: NTU Global Connect Fellowship" or "Fix: EPFL deadline updated to Nov 15"
   - The official source URL confirming the information
4. One of the maintainers will review and merge

---

## Updating deadlines each cycle

If you're a regular contributor:
- Check `deadlines.md` before each major application season (Aug, Nov, Jan)
- Cross-reference against official sites
- Update status emojis: 🔴 🟠 🟡 🟢 ⚫ as appropriate
- Keep "next cycle" entries — don't delete past-deadline items

---

## Questions

Open an issue if you're unsure where something fits, or if a program has complex eligibility that doesn't fit the standard format.
